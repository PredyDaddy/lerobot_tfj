# GROOT RL Docs

This directory contains the session-specific written notes for the GROOT RL training and deployment work.

Files:

- `groot_rl_how_rl_is_added_20260324_zh.md`
  - A focused teaching note explaining, in plain language, exactly how RL was added into the current GROOT implementation.
- `groot_rl_complete_knowledge_for_ppt_20260318_zh.md`
  - Single-document knowledge base covering concepts, code changes, validation results, deployment decisions, and a ready-to-use PPT outline.
- `groot_rl_architecture_and_operations_20260318_zh.md`
  - High-level summary of what was built, what is safe to use on robot, and how the training and direct inference paths are split.
- `groot_rl_python_source_index_20260318_zh.md`
  - Index of the copied implementation files and what each one is responsible for.
- `openclaw_groot_server.md`
  - Existing server-side notes that were already present in the repo and are relevant to the GROOT SO101 / OpenClaw path.
